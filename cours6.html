2. Charger un fichier audio

La Web Audio API travaille sur des AudioBuffer : des tableaux de samples en mémoire. Pour charger un fichier, on utilise fetch puis decodeAudioData.

Visualisation — un AudioBuffer contient des échantillons

À gauche, le signal audio continu est représenté par sa forme d'onde. Les points montrent les samples conservés en mémoire dans l’AudioBuffer. Le fichier n’est donc pas « une onde » stockée telle quelle : il devient une suite de valeurs numériques. 

async function chargerAudio(url) {
    const reponse = await fetch(url);
    const donnees = await reponse.arrayBuffer();
    const buffer = await audioCtx.decodeAudioData(donnees);
    return buffer;
}

Lire le buffer

const source = audioCtx.createBufferSource();
source.buffer = buffer;

source.connect(audioCtx.destination);
source.start();

Contrôle de la lecture

Méthode / propriétéRôle
start(when, offset)Démarre la lecture
stop(when)Arrête la lecture
playbackRateVitesse de lecture (1 = normal)
loopLecture en boucle
onendedÉvénement de fin de lecture
Attention :

Un AudioBufferSourceNode ne peut être démarré qu'une seule fois. Pour rejouer un son, il faut en créer un nouveau.

3. Effets audio simples

Écho (delay)

Un DelayNode retarde le signal d'un temps donné. En rebouclant partiellement la sortie sur l'entrée via un gain, on crée un écho répété.

Visualisation — comment un Delay crée un écho

0,30 s 0,40

Le premier pic est le son direct. Les pics suivants sont des copies retardées et atténuées. Augmentez le feedback pour voir apparaître davantage de répétitions. 

const delay = audioCtx.createDelay();
delay.delayTime.value = 0.3;

const feedback = audioCtx.createGain();
feedback.gain.value = 0.4;

source.connect(delay);
delay.connect(feedback);
feedback.connect(delay);
delay.connect(audioCtx.destination);

Réverbération (convolver)

Un ConvolverNode applique une réponse impulsionnelle (IR) au signal. Cela simule l'acoustique d'un lieu (église, salle de concert, etc.). 

const convolver = audioCtx.createConvolver();
convolver.buffer = reponseImpulsionnelle;

source.connect(convolver);
convolver.connect(audioCtx.destination);

Autres effets

NœudEffet

StereoPannerNodePosition stéréo
DynamicsCompressorNodeCompression dynamique

4. Analyse du signal

Pour visualiser un son, il faut l'analyser. Deux représentations complémentaires :

Domaine Représentation Usage
Temporel Amplitude en fonction du temps Oscilloscope, forme d'onde
Fréquentiel Amplitude en fonction de la fréquence Spectre, analyse harmonique
Analogie :

Le domaine temporel montre « comment le son vibre ». Le domaine fréquentiel montre « quelles fréquences composent le son ».

Comparaison — même son, deux lectures

Domaine temporel : amplitude au cours du temps
Domaine fréquentiel : énergie par fréquence

La forme d’onde montre les variations instantanées du signal. Le spectre révèle au contraire les composantes fréquentielles cachées dans ce signal complexe.

5. Transformée de Fourier

La transformée de Fourier décompose un signal en une somme de sinusoïdes. En informatique, on utilise la FFT (Fast Fourier Transform), qui calcule cette décomposition rapidement.

Principe intuitif

Un accord de piano est un signal complexe. La FFT permet d'extraire les fréquences qui le composent : on voit apparaître des pics aux fréquences des notes jouées.

Visualisation — décomposer un signal en fréquences

Le signal complexe du haut peut être vu comme la somme de plusieurs sinusoïdes. Chaque composante produit un pic identifiable dans le spectre du bas.

Sortie de la FFT

La FFT produit un tableau de valeurs complexes. En pratique, on utilise la magnitude (module) pour obtenir l'amplitude de chaque bande de fréquences.

IndiceFréquence
00 Hz (DC)
1échantillonnage / taille
nn × échantillonnage / taille
Dans la pratique :

Le AnalyserNode de la Web Audio API effectue la FFT pour nous. Il suffit de récupérer le tableau de magnitudes.

6. Le nœud AnalyserNode

Le AnalyserNode s'insère dans le graphe audio et fournit en temps réel deux tableaux :

  • getByteTimeDomainData() : forme d'onde ;
  • getByteFrequencyData() : spectre de fréquences.

Visualisation — les deux sorties de l'AnalyserNode

Un seul analyseur permet donc d’observer deux aspects du même signal : les samples dans le temps et leur répartition en bandes de fréquences.

Création

const analyseur = audioCtx.createAnalyser();

analyseur.fftSize = 2048;              // taille de la FFT
analyseur.smoothingTimeConstant = 0.8; // lissage temporel

source.connect(analyseur);
analyseur.connect(audioCtx.destination);

Paramètres

Visualisation — fftSize et résolution fréquentielle

2048 → 1024 bandes

Plus fftSize est grand, plus les bandes fréquentielles sont fines, mais l’analyse porte sur une fenêtre temporelle plus longue.

ParamètreRôle
fftSize Nombre d'échantillons analysés (puissance de 2). Plus il est grand, plus la résolution fréquentielle est fine.
frequencyBinCount Nombre de bandes = fftSize / 2
smoothingTimeConstant Lissage entre deux images (0 = aucun, 1 = très lissé)

Récupérer les données

const donneesFreq = new Uint8Array(analyseur.frequencyBinCount);

analyseur.getByteFrequencyData(donneesFreq);

// donneesFreq[i] ∈ [0, 255]
// i correspond à une bande de fréquences
Correspondance fréquence / indice : 
fréquence = i × (sampleRate / 2) / frequencyBinCount

7. Visualisation sur Canvas

Barres de spectre

Chaque bande de fréquence est représentée par une barre verticale dont la hauteur dépend de l'amplitude.

Visualisation — barres de spectre en temps réel

220 Hz

Chaque barre correspond à une bande de fréquences. Une note fondamentale et ses harmoniques produisent plusieurs zones d’énergie. 

const largeur = canvas.width / donneesFreq.length;

for (let i = 0; i < donneesFreq.length; i++) {
    const hauteur = donneesFreq[i] / 255 * canvas.height;

    ctx.fillRect(
        i * largeur,
        canvas.height - hauteur,
        largeur - 1,
        hauteur
    );
}

Forme d'onde

const donneesTemp = new Uint8Array(analyseur.fftSize);

analyseur.getByteTimeDomainData(donneesTemp);

ctx.beginPath();
ctx.moveTo(0, canvas.height / 2);

for (let i = 0; i < donneesTemp.length; i++) {
    const x = i / donneesTemp.length * canvas.width;
    const y = donneesTemp[i] / 128 * canvas.height / 2;
    ctx.lineTo(x, y);
}

ctx.stroke();

Cercles réactifs

Visualisation — la forme d'onde

3 cycles

Ici, on visualise directement l’amplitude du signal au cours du temps, comme un oscilloscope.

Une autre approche consiste à moduler la taille de cercles selon l'amplitude globale du signal. 

let somme = 0;
for (const v of donneesFreq) somme += v;
const intensite = somme / donneesFreq.length / 255;

const rayon = 50 + intensite * 150;
ctx.arc(canvas.width / 2, canvas.height / 2, rayon, 0, Math.PI * 2);
ctx.stroke();

8. Synchronisation son / image

Pour synchroniser un effet visuel avec la musique, on peut :

Visualisation — deux horloges, une référence audio

La ligne supérieure représente l’horloge audio. Les marqueurs visuels sont déclenchés à des instants précis de cette horloge. Le but est d’éviter que l’animation dépende uniquement de la cadence graphique.

  • utiliser le currentTime du contexte audio ;
  • analyser le signal à chaque image ;
  • programmer des événements avec setValueAtTime.

Horloge audio

const temps = audioCtx.currentTime;   // en secondes

Contrairement à performance.now(), cette horloge est échantillon-précise et reste synchronisée avec le son, même en cas de ralentissement graphique.

Bonne pratique :

Pour une synchronisation précise, utilisez toujours audioCtx.currentTime comme référence temporelle pour la programmation audio.

Exemple : flash visuel synchronisé

const temps = audioCtx.currentTime;

// Programmer un gain
const gain = audioCtx.createGain();
gain.gain.setValueAtTime(0, temps);
gain.gain.linearRampToValueAtTime(1, temps + 0.05);
gain.gain.linearRampToValueAtTime(0, temps + 0.3);

// Programmer un flash (mémoriser l'instant)
flashs.push({ temps: temps, duree: 0.3 });

Dans la boucle de rendu, on compare audioCtx.currentTime aux instants programmés pour déclencher l'effet visuel.

9. TP 1 — Visualiseur audio

Moyen

Objectif

Charger un fichier audio (ou générer un son) et afficher sur Canvas un visualiseur à barres.

Étapes

  1. Créer un AudioContext et un oscillateur ou charger un fichier.

10. TP 2 — Spectrogramme

Difficile

Objectif

Construire un spectrogramme : représentation 2D où l'axe horizontal est le temps, l'axe vertical la fréquence, et la couleur l'amplitude.

Principe

À chaque image, on décale l'image existante d'un pixel vers la gauche, puis on dessine une nouvelle colonne à droite représentant le spectre instantané.

Visualisation — lire un spectrogramme

3

Horizontalement : le temps avance vers la droite. Verticalement : les fréquences. L’intensité lumineuse représente l’amplitude. Une trace permet donc de voir comment le contenu fréquentiel évolue dans le temps. 

ctx.drawImage(
    canvas,
    -1, 0,
    canvas.width, canvas.height
);

for (let i = 0; i < donneesFreq.length; i++) {
    const y = canvas.height - i / donneesFreq.length * canvas.height;
    const intensite = donneesFreq[i];

    ctx.fillStyle = `rgb(${intensite}, ${intensite}, ${intensite})`;
    ctx.fillRect(canvas.width - 1, y, 1, 1);
}

Extension

Utiliser une palette de couleurs (bleu → rouge) pour un rendu plus lisible.

11. TP 3 — Scène réactive au son

Difficile

Objectif

Créer une scène graphique dont les éléments réagissent à la musique : taille, couleur, position, rotation.

Contraintes

  • Utiliser les données fréquentielles pour moduler au moins trois paramètres visuels ;
  • Utiliser les données temporelles pour un effet de traînée ou d'oscillation ;
  • Séparer les basses, médiums et aigus pour des réactions distinctes.

Indice

Pour séparer les bandes :

Visualisation — basses, médiums et aigus pilotent la scène

Les basses peuvent contrôler la taille, les médiums la rotation et les aigus la position ou le nombre d’éléments. C’est le principe d’une scène graphique réellement réactive au contenu musical. 

const basses = moyenne(donneesFreq, 0, 10);
const mediums = moyenne(donneesFreq, 10, 50);
const aigus = moyenne(donneesFreq, 50, 100);

12. Démonstration interactive

Cliquez sur « Activer l'audio » puis lancez une note. Le visualiseur affiche le spectre en temps réel.

Avant de lancer la démonstration — ce qui se passe réellement

Chaîne logique : Oscillateur → Gain → AnalyserNode → sortie audio. Le même signal peut donc être entendu et mesuré en même temps, puis transformé en données utilisables par Canvas.

À observer :
  • Le spectre se concentre autour de la fréquence de la note.
  • Une note plus aiguë décale le pic vers la droite.
  • L'amplitude du pic dépend du volume.
