Du cube à la scène : POO, rotations, caméra, projection et éclairage

Le but de cette journée n'est pas de fabriquer un moteur 3D professionnel. Le but est de comprendre une idée simple : nous décrivons des objets dans l'espace, puis nous calculons comment ils doivent apparaître sur un écran 2D.

2. L'idée centrale : Canvas reste en 2D

Un élément <canvas> possède une surface plate. Quand nous faisons :

ctx.fillRect(100, 80, 20, 20);

Canvas comprend seulement une position x et une position y. Il n'existe pas de paramètre z.

En 2D

Nous avons directement :

(x, y) → Canvas

En 3D simulée

Nous faisons d'abord :

(x, y, z)
   ↓
calculs
   ↓
(x écran, y écran)
   ↓
Canvas
Phrase à retenir : la 3D ne change pas le pinceau du Canvas ; elle change les calculs qui déterminent où placer ce pinceau.

Une analogie : photographier une boîte

Imaginez une boîte réelle devant vos yeux. La boîte existe dans l'espace. Votre œil, lui, reçoit une image plane. Notre programme fait quelque chose de comparable : il possède des coordonnées 3D puis calcule une image 2D.

3. Première notion : le point 3D

En 2D, un point est décrit par deux valeurs :

const point = { x: 100, y: 50 };

En 3D, nous ajoutons la profondeur :

const point = { x: 100, y: 50, z: 200 };
CoordonnéeIdée intuitiveExemple
Xgauche ↔ droite+100 = vers la droite
Yhaut ↔ bas dans notre modèle 3D+100 = vers le haut
Zprofondeur+100 = plus loin selon la convention choisie
Attention à Canvas : Canvas 2D utilise généralement un axe Y qui augmente vers le bas. Notre espace 3D pédagogique peut utiliser Y vers le haut. Lors de la projection, nous devrons adapter cette convention.

4. Concevoir notre premier objet : le Cube 🧊

Avant de parler de caméra ou de projection, nous allons d'abord concevoir l'objet 3D lui-même. À ce stade, notre cube existe uniquement sous forme de données : il n'est pas encore affiché à l'écran.

Idée pédagogique : construire un cube ne signifie pas encore le voir. Nous définissons d'abord sa géométrie, puis nous apprendrons à le transformer, à le regarder avec une caméra et enfin à le projeter sur Canvas.

4.1 Pourquoi utiliser la POO ici ?

Un objet 3D possède naturellement un état : une position, une rotation et une géométrie. La POO nous permet de regrouper ces informations dans des objets faciles à manipuler.

Classe

Le modèle général. Exemple : Cube.

Objet

Une instance concrète. Exemple : cubeRouge.

Méthode

Une action de l'objet. Exemple : tournerY().

4.2 Une classe de base : Objet3D

class Objet3D {
    constructor(x, y, z) {
        this.position = { x, y, z };
        this.rotation = { x: 0, y: 0, z: 0 };
    }

    tournerX(angle) {
        this.rotation.x += angle;
    }

    tournerY(angle) {
        this.rotation.y += angle;
    }

    tournerZ(angle) {
        this.rotation.z += angle;
    }
}

Objet3D ne représente pas encore une forme précise. Il contient seulement ce que plusieurs objets 3D auront en commun : une position et une rotation.

4.3 Les 8 sommets du cube

Un cube possède 8 sommets. Chaque sommet est un point local (x, y, z) situé autour du centre du cube.

class Cube extends Objet3D {
    constructor(x, y, z, taille) {
        super(x, y, z);

        const s = taille / 2;

        this.sommets = [
            {x:-s,y:-s,z:-s}, {x:s,y:-s,z:-s},
            {x:s,y:s,z:-s},   {x:-s,y:s,z:-s},
            {x:-s,y:-s,z:s},  {x:s,y:-s,z:s},
            {x:s,y:s,z:s},    {x:-s,y:s,z:s}
        ];
    }
}

4.4 Les 12 arêtes

Une arête relie deux sommets. Au lieu de recopier les coordonnées, nous stockons seulement les indices des sommets à relier.

this.aretes = [
    [0,1],[1,2],[2,3],[3,0],
    [4,5],[5,6],[6,7],[7,4],
    [0,4],[1,5],[2,6],[3,7]
];

4.5 Les 6 faces

Nous définissons déjà les faces, car elles seront utiles plus tard pour le rendu plein et l'éclairage.

this.faces = [
    [0,1,2,3],
    [4,5,6,7],
    [0,1,5,4],
    [2,3,7,6],
    [1,2,6,5],
    [0,3,7,4]

8 sommets→ 12 arêtes→ 6 faces→ 1 Cube

5. Faire tourner le cube : transformations 3D 🔄

Un cube possède des sommets. Pour faire tourner le cube, nous devons faire tourner chacun de ses sommets.

5.1 Rotation autour de X

function rotationX(p, angle) {
    const c = Math.cos(angle);
    const s = Math.sin(angle);

    return {
        x: p.x,
        y: p.y * c - p.z * s,
        z: p.y * s + p.z * c
    };
}

Nous ne demandons pas encore de mémoriser cette formule. Il faut surtout comprendre son rôle : elle reçoit un point et renvoie le même point après rotation autour de X.

5.2 Rotation autour de Y et Z

function rotationY(p, angle) {
    const c = Math.cos(angle);
    const s = Math.sin(angle);
    return {
        x: p.x * c + p.z * s,
        y: p.y,
        z: -p.x * s + p.z * c
    };
}

function rotationZ(p, angle) {
    const c = Math.cos(angle);
    const s = Math.sin(angle);
    return {
        x: p.x * c - p.y * s,
        y: p.x * s + p.y * c,
        z: p.z
    };
}

Rotation X

Le point tourne comme autour d'une barre gauche-droite.

Rotation Y

Le point tourne comme autour d'une barre verticale.

Rotation Z

Le point tourne dans le plan de l'écran.

Règle mentale : une fonction de transformation ne dessine rien. Elle transforme des données. Le dessin arrive seulement après la projection.
Important : les rotations modifient les coordonnées 3D. Elles ne dessinent rien. Nous allons maintenant introduire la caméra, puis la projection.

5.3 Ordre des opérations

sommet local
    ↓
rotation X
    ↓
rotation Y
    ↓
rotation Z
    ↓
translation de l'objet
    ↓
projection caméra
    ↓
dessin Canvas

L'ordre exact peut changer le résultat. C'est pourquoi il est utile de séparer les étapes plutôt que de tout mélanger dans une seule fonction.

6. La caméra : choisir le point de vue 📷

Notre cube existe et peut tourner, mais nous devons maintenant décider depuis quel point de vue nous l'observons. C'est le rôle de la caméra.

Nous pouvons maintenant encapsuler ce rôle dans une classe :

class Camera {
    constructor(x, y, z, distanceFocale) {
        this.position = { x, y, z };
        this.d = distanceFocale;
    }

    project(point, largeur, hauteur) {
        // calcul de la projection
    }
}

La responsabilité est claire : la caméra sait comment transformer un point de l'espace en point écran.

Objet→Point 3D→Camera.project()→Point écran
Bonne pratique : l'objet 3D ne devrait pas connaître les dimensions du Canvas. La caméra s'occupe de la projection ; le renderer s'occupe du dessin.

7. Projection : transformer la 3D en coordonnées Canvas 🎯

Voici le moment où nous répondons à une question essentielle : comment passer de (x,y,z) à une position sur l'écran ?

7.1 Pourquoi les objets lointains paraissent-ils plus petits ?

Une photographie nous montre qu'un objet proche occupe davantage de place qu'un objet identique éloigné. Nous allons reproduire cet effet avec un facteur de perspective.

Dans le modèle simplifié utilisé dans ce cours :

facteur = d / (d + z)

où d représente une distance focale simplifiée et z la profondeur.

ProfondeurEffet
z petitfacteur plus grand → objet visuellement plus grand
z grandfacteur plus petit → objet visuellement plus petit

7.2 Calcul des coordonnées écran

const facteur = d / (d + point.z);
const xEcran = centreX + point.x * facteur;
const yEcran = centreY - point.y * facteur;
Pourquoi - point.y ? Parce que notre repère 3D pédagogique considère Y positif vers le haut, alors que Canvas considère Y positif vers le bas.

7.3 Projection interactive

Le point rouge représente un même point 3D. Modifiez la distance focale pour observer l'effet de la projection.

8. Éclairage simple : donner du relief 💡

Une surface tournée vers une source lumineuse paraît plus éclairée qu'une surface tournée dans une autre direction.

Pour un modèle simple, nous utilisons le produit scalaire entre une normale et une direction de lumière.

intensite = max(0, normale.x * lumiere.x
                  + normale.y * lumiere.y
                  + normale.z * lumiere.z);

Nous pouvons ensuite faire varier une couleur ou une luminosité à partir de cette intensité.

8.1 Normale d'une face

Pour une face, nous pouvons prendre deux vecteurs situés sur la surface puis calculer leur produit vectoriel. Dans un cours d'introduction, il suffit de comprendre le rôle :

Face→Normale→Comparaison avec lumière→Intensité

8.2 Pourquoi l'éclairage arrive maintenant ?

Le cube possède déjà ses faces, et nous savons maintenant les transformer puis les observer depuis une caméra. L'éclairage devient donc concret : il sert à différencier visuellement les faces selon leur orientation.

Progression : cube → rotation → caméra → projection → lumière.

9. La scène : organiser plusieurs objets

Une fois que nous avons une classe Cube, nous pouvons créer plusieurs cubes sans recopier leur code.

const cube1 = new Cube(-140, 0, 350, 100);
const cube2 = new Cube(140, 0, 500, 160);
const cube3 = new Cube(0, 70, 700, 80);

Mais trois objets signifient aussi qu'il faut organiser leur rendu. C'est le rôle de Scene.

class Scene {
    constructor() {
        this.objects = [];
    }

    add(object) {
        this.objects.push(object);
    }

    update() {
        for (const object of this.objects) {
            object.update();
        }
    }

    draw(ctx, camera) {
        for (const object of this.objects) {
            object.draw(ctx, camera);
        }
    }
}

10. La profondeur : qui doit être dessiné en premier ?

Imaginez deux cubes qui se chevauchent. Si nous dessinons le cube proche puis le cube éloigné, le cube éloigné peut recouvrir le proche. L'ordre de dessin devient donc important.

10.1 L'algorithme du peintre

L'idée est comparable à un peintre qui commence par le décor lointain puis ajoute les éléments proches.

scene.objects.sort((a, b) => {
    return b.position.z - a.position.z;
});

Dans la convention de ce cours, nous dessinons les objets les plus éloignés avant les plus proches.

Attention : ce tri par objet est une simplification. Pour des objets qui s'interpénètrent ou des faces qui se croisent, il faut des techniques plus avancées. Ici, l'objectif est de comprendre le principe.

10.2 Pourquoi la profondeur appartient-elle à la scène ?

Parce que ce n'est pas un cube isolé qui sait quel autre cube doit être dessiné avant lui. C'est la scène qui connaît l'ensemble des objets.

draw(ctx, camera) {
    const objets = [...this.objects];

    objets.sort((a, b) => b.position.z - a.position.z);

    for (const objet of objets) {
        objet.draw(ctx, camera);
    }
}

ctx.beginPath();

11.2 Trier aussi les faces

Si le cube tourne, une face peut devenir devant une autre. Nous pouvons calculer une profondeur moyenne :

const profondeur = face.reduce((somme, index) => {
    return somme + sommets[index].z;
}, 0) / face.length;

Puis dessiner les faces de la plus éloignée à la plus proche.

Étape importante : le même principe revient : calculer → trier → dessiner.

12.1 La classe Vec3 (vecteur 3D)

class Vec3 {
    constructor(x = 0, y = 0, z = 0) {
        this.x = x;
        this.y = y;
        this.z = z;
    }

    add(v) {
        return new Vec3(this.x + v.x, this.y + v.y, this.z + v.z);
    }
}

12.2 Les fonctions de rotation

function rotationX(p, angle) {
    const c = Math.cos(angle);
    const s = Math.sin(angle);
    return new Vec3(p.x, p.y * c - p.z * s, p.y * s + p.z * c);
}

function rotationY(p, angle) {
    const c = Math.cos(angle);
    const s = Math.sin(angle);
    return new Vec3(p.x * c + p.z * s, p.y, -p.x * s + p.z * c);
}

function rotationZ(p, angle) {
    const c = Math.cos(angle);
    const s = Math.sin(angle);
    return new Vec3(p.x * c - p.y * s, p.x * s + p.y * c, p.z);
}

12.3 La classe Camera

class Camera {
    constructor(distanceFocale = 520) {
        this.d = distanceFocale;
    }

    project(point, largeur, hauteur) {
        const facteur = this.d / (this.d + point.z);
        return {
            x: largeur / 2 + point.x * facteur,
            y: hauteur / 2 - point.y * facteur
        };
    }
}

12.4 La classe Objet3D

class Objet3D {
    constructor(x, y, z) {
        this.position = new Vec3(x, y, z);
        this.rotation = new Vec3(0, 0, 0);
    }

    tournerX(angle) {
        this.rotation.x += angle;
    }

    tournerY(angle) {
        this.rotation.y += angle;
    }

    tournerZ(angle) {
        this.rotation.z += angle;
    }

    transform(point) {
        let p = rotationX(point, this.rotation.x);
        p = rotationY(p, this.rotation.y);
        p = rotationZ(p, this.rotation.z);
        return p.add(this.position);
    }
}

12.5 La classe Cube

class Cube extends Objet3D {
    constructor(x, y, z, taille, couleur = '#d9e6ed') {
        super(x, y, z);

        const s = taille / 2;
        this.couleur = couleur;

        // 8 sommets
        this.sommets = [
            new Vec3(-s, -s, -s), new Vec3( s, -s, -s),
            new Vec3( s,  s, -s), new Vec3(-s,  s, -s),
            new Vec3(-s, -s,  s), new Vec3( s, -s,  s),
            new Vec3( s,  s,  s), new Vec3(-s,  s,  s)
        ];

        // 12 arêtes
        this.aretes = [
            [0,1],[1,2],[2,3],[3,0],
            [4,5],[5,6],[6,7],[7,4],
            [0,4],[1,5],[2,6],[3,7]
        ];
    }

    draw(ctx, camera) {
        // 1. Transformer les sommets
        const sommetsTransformes = this.sommets.map(s => this.transform(s));

        // 2. Projeter les sommets
        const sommetsProjetes = sommetsTransformes.map(s =>
            camera.project(s, ctx.canvas.width, ctx.canvas.height)
        );

        // 3. Dessiner les arêtes
        ctx.strokeStyle = this.couleur;
        ctx.lineWidth = 1.5;
        ctx.beginPath();

        for (const [a, b] of this.aretes) {
            ctx.moveTo(sommetsProjetes[a].x, sommetsProjetes[a].y);
            ctx.lineTo(sommetsProjetes[b].x, sommetsProjetes[b].y);
        }

        ctx.stroke();
    }
}

12.6 La classe Scene

class Scene {
    constructor() {
        this.objects = [];
    }

    add(objet) {
        this.objects.push(objet);
    }

    draw(ctx, camera) {
        // Trier les objets du plus loin au plus proche (algorithme du peintre)
        const objetsTries = [...this.objects].sort(
            (a, b) => b.position.z - a.position.z
        );

        for (const objet of objetsTries) {
            objet.draw(ctx, camera);
        }
    }
}

12.7 Utilisation complète

// Créer le canvas et le contexte
const canvas = document.getElementById('sceneCanvas');
const ctx = canvas.getContext('2d');

// Créer la caméra
const camera = new Camera(520);

// Créer la scène
const scene = new Scene();

// Ajouter des cubes
scene.add(new Cube(-150,  20, 430, 150, '#ff6b6b'));
scene.add(new Cube( 150, -15, 610, 190, '#6bcbff'));
scene.add(new Cube(   0, 125, 800, 105, '#ffd93d'));

// Boucle d'animation
function animer(temps) {
    // Effacer le canvas
    ctx.fillStyle = '#101820';
    ctx.fillRect(0, 0, canvas.width, canvas.height);

    // Faire tourner les cubes
    scene.objects.forEach((objet, i) => {
        objet.tournerX(0.01 * (i + 1));
        objet.tournerY(0.015 * (i + 1));
    });

    // Dessiner la scène
    scene.draw(ctx, camera);

    requestAnimationFrame(animer);
}

Résumé des responsabilités :
  • Vec3 : représente un point ou vecteur 3D.
  • rotationX/Y/Z : transforment un point 3D.
  • Camera : projette un point 3D en point 2D écran.
  • Objet3D : base commune (position, rotation, transformation).
  • Cube : géométrie concrète + dessin de ses arêtes.
  • Scene : collection d'objets + tri par profondeur + rendu global.

16. Bilan du Jour 3

Les 10 idées essentielles

  1. Un point 3D possède trois coordonnées : x, y, z.
  2. Canvas reste un espace 2D.
  3. La projection transforme un point 3D en point écran.
  4. La perspective fait paraître les objets lointains plus petits.
  5. La caméra représente le point de vue.
  6. Les rotations permettent de transformer les sommets d'un objet.
  7. La POO permet de regrouper données et comportements dans des objets.
  8. Une scène contient plusieurs objets et peut gérer leur ordre de rendu.
  9. Les faces permettent de passer du filaire au rendu plein.
  10. Une lumière simple peut utiliser l'orientation des faces pour moduler leur apparence.
Le schéma à mémoriser :

Créer → Transformer → Placer → Projeter → Trier → Dessiner

Questions de vérification

1. Pourquoi Canvas ne peut-il pas dessiner directement un point (x,y,z) ?
2. Pourquoi avons-nous besoin d'une projection ?
3. Quel est l'intérêt de Objet3D ?
4. Pourquoi la scène doit-elle connaître plusieurs objets ?
5. Pourquoi le tri par profondeur est-il nécessaire ?
6. Quelle différence entre une arête et une face ?
7. Que représente la normale d'une face ?
Réponses courtes
  1. Canvas dessine sur une surface 2D.
  2. Pour convertir les coordonnées 3D en coordonnées écran.
  3. Pour regrouper position, rotation et comportements communs.
  4. Pour organiser la scène et le rendu global.
  5. Pour éviter qu'un objet lointain soit dessiné par-dessus un objet proche.
  6. Une arête relie deux sommets ; une face regroupe plusieurs sommets pour former une surface.
  7. Elle indique l'orientation de la surface.

Ce que l'on ne demande pas encore

À ce stade, l'étudiant n'a pas besoin de connaître les moteurs 3D, les matrices 4×4, les shaders, WebGL ou les algorithmes avancés de visibilité. Ces notions pourront venir plus tard. Le but du Jour 3 est d'acquérir un modèle mental solide de la chaîne de rendu 3D.
