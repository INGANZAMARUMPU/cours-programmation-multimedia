2. Pourquoi la 3D sur Canvas 2D ?

Un Canvas est une surface plate : chaque pixel possède deux coordonnées (x, y). Pourtant, l'œil humain perçoit la profondeur grâce à plusieurs indices (taille, perspective, occlusion, ombres).

Faire de la 3D sur Canvas consiste donc à simuler ces indices : on calcule les positions dans un espace à trois dimensions, puis on les projette sur le plan 2D de l'écran.

Idée directrice :

La 3D sur Canvas ne change pas la façon de dessiner — on utilise toujours fillRect, arc, moveTo/lineTo. Ce qui change, c'est la façon de calculer les coordonnées avant de dessiner.

WebGL

API bas niveau, accélérée par le GPU, pour la 3D temps réel.

Bibliothèques de haut niveau construites sur WebGL.

3. Représenter un point en 3D

Un point dans l'espace possède trois coordonnées : 

const point = { x: 100, y: 50, z: 200 };

Contrairement au Canvas 2D, il n'y a pas de convention universelle pour l'orientation des axes. En infographie, on utilise souvent le repère suivant :

AxeDirection usuelle
Xvers la droite
Yvers le haut
Zvers l'observateur (ou l'inverse selon la convention)
Attention :

Sur Canvas 2D, l'axe Y descend. En 3D, on utilise souvent un axe Y qui monte. Il faudra donc inverser Y lors de la projection finale.

Illustration comparative — 2D contre 3D

Repère Canvas 2D

Un point est décrit uniquement par (x, y). L'écran reçoit directement ces coordonnées.

Repère 3D avant projection

Un point possède (x, y, z). La profondeur z n'est pas directement dessinée : elle influence la projection.

À observer : la 3D ajoute une information de profondeur, mais le résultat final reste un dessin 2D.

4. La caméra

La caméra représente le point de vue de l'observateur. Elle est définie par :

  • une position dans l'espace (cx, cy, cz) ;
  • une direction de visée (souvent l'axe Z) ;
  • un plan de projection situé à une distance d devant elle.

Pour simplifier, on place la caméra à l'origine et on regarde vers les Z positifs. Un point est visible s'il est devant la caméra, c'est-à-dire si z > 0 (ou z > d).

Analogie :

Imaginez que vous regardez par une fenêtre. La caméra est votre œil, le plan de projection est la vitre, et l'écran est la photo prise à travers la vitre.

Illustration comparative — objet, caméra et écran

La caméra observe la scène et le plan de projection transforme la position spatiale en position sur l'écran.

5. Projection perspective

C'est le cœur de la 3D. La projection transforme un point (x, y, z) en un point 2D (sx, sy) sur l'écran.

Principe

Plus un objet est loin, plus il paraît petit. C'est la perspective. Mathématiquement, on divise les coordonnées par la profondeur z : 

const d = 400; // distance focale

function projeter(point) {
    const facteur = d / (d + point.z);

    return {
        x: point.x * facteur,
        y: -point.y * facteur   // inversion de Y pour Canvas
    };
}

Interprétation

CasEffet
z = 0L'objet est au niveau de la caméra : taille normale.
z > 0L'objet s'éloigne : il rétrécit.
z < 0L'objet est derrière la caméra : il faut le masquer.
Point crucial :

Le signe et le décalage de z dépendent de la convention choisie. L'essentiel est de rester cohérent dans tout le programme.

Ajout du centre de l'écran

La caméra regarde vers le centre du Canvas. On translate donc le résultat : 

const centreX = canvas.width / 2;
const centreY = canvas.height / 2;

function projeter(point) {
    const facteur = d / (d + point.z);

    return {
        x: centreX + point.x * facteur,
        y: centreY - point.y * facteur
    };
}

Illustration interactive — effet de perspective

300

Déplacez le curseur : plus z augmente, plus le facteur d/(d+z) diminue et plus l'objet paraît petit.

6. Transformations 3D

Comme en 2D, on peut translater, tourner et redimensionner un point 3D. La nouveauté, c'est qu'il existe trois rotations, une autour de chaque axe.

Rotation autour de l'axe X

function rotationX(p, angle) {
    const c = Math.cos(angle);
    const s = Math.sin(angle);

    return {
        x: p.x,
        y: p.y * c - p.z * s,
        z: p.y * s + p.z * c
    };
}

Rotation autour de l'axe Y

function rotationY(p, angle) {
    const c = Math.cos(angle);
    const s = Math.sin(angle);

    return {
        x: p.x * c + p.z * s,
        y: p.y,
        z: -p.x * s + p.z * c
    };
}

Rotation autour de l'axe Z

function rotationZ(p, angle) {
    const c = Math.cos(angle);
    const s = Math.sin(angle);

    return {
        x: p.x * c - p.y * s,
        y: p.x * s + p.y * c,
        z: p.z
    };
}
Remarque :

Ces formules sont directement issues des matrices de rotation 3×3. On peut les combiner en appliquant successivement plusieurs rotations.

Translation et échelle

function translater(p, dx, dy, dz) {
    return { x: p.x + dx, y: p.y + dy, z: p.z + dz };
}

function echelle(p, k) {
    return { x: p.x * k, y: p.y * k, z: p.z * k };
}

Illustration comparative — trois axes de rotation

Rotation X

L'axe X reste invariant ; Y et Z changent.

Rotation Y

L'axe Y reste invariant ; X et Z changent.

Rotation Z

L'axe Z reste invariant ; la rotation ressemble à une rotation 2D.

7. Gestion de la profondeur

En 3D, plusieurs objets peuvent se superposer à l'écran alors qu'ils sont à des profondeurs différentes. Deux techniques simples :

Algorithme du peintre

On trie les objets du plus lointain au plus proche, puis on les dessine dans cet ordre. Les objets proches recouvrent naturellement les objets lointains. 

objets.sort((a, b) => b.z - a.z);

for (const objet of objets) {
    dessiner(objet);
}

Taille proportionnelle à la distance

On module la taille de l'objet en fonction de sa profondeur (via le facteur de projection).

Limite :

L'algorithme du peintre ne fonctionne pas dans tous les cas (objets qui s'interpénètrent). Un vrai moteur 3D utilise un Z-buffer (tampon de profondeur). Nous nous contenterons de l'algorithme du peintre, qui est suffisant pour des scènes simples.

Illustration comparative — ordre de dessin

Sans tri

Le dernier objet dessiné peut recouvrir un objet qui devrait être devant ou derrière.

Algorithme du peintre

On dessine du plus lointain au plus proche.

Limite : le tri par profondeur moyenne reste une simplification ; les objets qui s'interpénètrent nécessitent une gestion plus avancée.

8. Rendu filaire

Le rendu filaire (wireframe) consiste à ne dessiner que les arêtes d'un objet. C'est la forme la plus simple de rendu 3D.

Définir un cube

const cube = {
    sommets: [
        { x: -50, y: -50, z: -50 },
        { x:  50, y: -50, z: -50 },
        { x:  50, y:  50, z: -50 },
        { x: -50, y:  50, z: -50 },
        { x: -50, y: -50, z:  50 },
        { x:  50, y: -50, z:  50 },
        { x:  50, y:  50, z:  50 },
        { x: -50, y:  50, z:  50 }
    ],

    aretes: [
        [0, 1], [1, 2], [2, 3], [3, 0],
        [4, 5], [5, 6], [6, 7], [7, 4],
        [0, 4], [1, 5], [2, 6], [3, 7]
    ]
};

Dessiner le cube

function dessinerCube(cube) {
    // 1. Transformer les sommets
    const transformes = cube.sommets.map(s =>
        rotationY(rotationX(s, angleX), angleY)
    );

    // 2. Projeter en 2D
    const projetes = transformes.map(projeter);

    // 3. Tracer les arêtes
    ctx.beginPath();
    ctx.strokeStyle = "white";

    for (const [a, b] of cube.aretes) {
        ctx.moveTo(projetes[a].x, projetes[a].y);
        ctx.lineTo(projetes[b].x, projetes[b].y);
    }

    ctx.stroke();
}

9. Faces et polygones

Pour un rendu plein, il faut définir les faces (polygones) de l'objet, puis les remplir avec fill(). 

const faces = [
    [0, 1, 2, 3], // face arrière
    [4, 5, 6, 7], // face avant
    [0, 1, 5, 4], // bas
    [2, 3, 7, 6], // haut
    [1, 2, 6, 5], // droite
    [0, 3, 7, 4]  // gauche
];

Dessiner une face

function dessinerFace(indices, projetes, couleur) {
    ctx.beginPath();
    ctx.moveTo(projetes[indices[0]].x, projetes[indices[0]].y);

    for (let i = 1; i < indices.length; i++) {
        ctx.lineTo(projetes[indices[i]].x, projetes[indices[i]].y);
    }

    ctx.closePath();
    ctx.fillStyle = couleur;
    ctx.fill();
    ctx.strokeStyle = "white";
    ctx.stroke();
}

Élimination des faces cachées

Une face est cachée si elle est orientée vers l'intérieur de l'objet. On calcule son produit vectoriel pour déterminer son orientation par rapport à la caméra. 

function faceVisible(p1, p2, p3) {
    // Produit vectoriel des deux arêtes
    const ux = p2.x - p1.x;
    const uy = p2.y - p1.y;
    const vx = p3.x - p1.x;
    const vy = p3.y - p1.y;

    // Signe de la composante Z
    return (ux * vy - uy * vx) > 0;
}
Simplification :

Pour un cube, on peut aussi se contenter de trier les faces par profondeur moyenne et de les dessiner de la plus lointaine à la plus proche.

Illustration comparative — face visible et face cachée

Deux faces peuvent avoir des orientations différentes par rapport à la caméra. Leur ordre et leur orientation influencent le rendu.

10. Éclairage simple

Pour donner du relief, on module la couleur d'une face en fonction de son orientation par rapport à une source de lumière.

Principe

On définit une direction de lumière, puis on calcule l'angle entre la normale de la face et cette direction. Plus l'angle est petit, plus la face est éclairée. 

function intensiteLumiere(normale, lumiere) {
    // Produit scalaire normalisé
    const dot = normale.x * lumiere.x +
                normale.y * lumiere.y +
                normale.z * lumiere.z;

    return Math.max(0, dot);
}

Application

const lumiere = { x: 0.5, y: 0.7, z: 0.5 };
const intensite = intensiteLumiere(normale, lumiere);

const couleur = `rgb(
    ${Math.round(200 * intensite)},
    ${Math.round(220 * intensite)},
    ${Math.round(255 * intensite)}
)`;
Résultat :

Les faces les mieux orientées vers la lumière apparaissent claires ; les autres sombres. C'est la base de tout éclairage en infographie.

12. TP 2 — Scène 3D

Difficile

Objectif

Construire une scène contenant plusieurs cubes à des profondeurs différentes, avec tri par profondeur.

Contraintes

  • Au moins 4 cubes ;
  • Chaque cube a une position (x, y, z) propre ;
  • Les cubes tournent sur eux-mêmes ;
  • Les cubes sont triés du plus lointain au plus proche avant dessin ;
  • Les faces sont remplies et éclairées.

Extension

Ajouter un déplacement de la scène avec les flèches du clavier (translation sur X et Y) et avec + / - pour le zoom (modification de la distance focale d).
