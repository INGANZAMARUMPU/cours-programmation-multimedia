2. Effacer et redessiner

Pour créer une animation, nous devons régulièrement effacer l'image précédente. 

ctx.clearRect(0, 0, canvas.width, canvas.height);

Le cycle devient :

1. Effacer → 2. Mettre à jour → 3. Dessiner → 4. Recommencer

3. Première animation

Une animation est obtenue en modifiant progressivement les propriétés d'un objet puis en redessinant la scène. 

let x = 0;

function animate() {
    ctx.clearRect(0, 0, canvas.width, canvas.height);

    ctx.fillStyle = "cyan";
    ctx.fillRect(x, 100, 60, 60);

    x += 2;

    requestAnimationFrame(animate);
}

animate();
Principe fondamental :

Une animation graphique est une succession très rapide d'images légèrement différentes.

Pourquoi requestAnimationFrame() ?

Cette fonction synchronise l'animation avec le rafraîchissement de l'écran (généralement 60 images par seconde). Elle est plus efficace et plus fluide que setInterval().

4. Séparer Update et Render

Dans une application interactive, il est préférable de séparer :

  • Update : calcul de l'état du programme ;
  • Render : affichage de cet état.
const player = {
    x: 100,
    y: 200,
    speed: 200
};

function update() {
    player.x += 2;
}

function render() {
    ctx.clearRect(0, 0, canvas.width, canvas.height);

    ctx.fillStyle = "cyan";
    ctx.fillRect(player.x, player.y, 50, 50);
}

function loop() {
    update();
    render();
    requestAnimationFrame(loop);
}

loop();

Cette séparation est le seul point d'architecture vraiment crucial de la séance. Elle structure toute application interactive :

5. Le temps et Delta Time

Si nous écrivons :

player.x += 5;

nous indiquons une distance par image. Or le nombre d'images affichées par seconde peut varier (60 Hz, 120 Hz, etc.). Le mouvement serait alors plus rapide sur un écran 120 Hz.

Pour rendre le mouvement indépendant du nombre d'images par seconde, nous utilisons le temps écoulé. 

let lastTime = performance.now();

function loop(currentTime) {
    const deltaTime = (currentTime - lastTime) / 1000;
    lastTime = currentTime;

    update(deltaTime);
    render();

    requestAnimationFrame(loop);
}

function update(dt) {
    player.x += player.speed * dt;
}

requestAnimationFrame(loop);
À comprendre :

Si speed = 200, cela signifie maintenant environ 200 pixels par seconde, quelle que soit la fréquence de rafraîchissement de l'écran.

6. Faire rebondir un objet

let x = 100;
let speed = 4;

function update() {
    x += speed;

    if (x <= 0 || x >= canvas.width - 50) {
        speed *= -1;
    }
}

Le changement de signe de la vitesse inverse la direction du mouvement.

7. Interaction avec le clavier

On peut détecter les touches avec les événements keydown et keyup. 

const keys = {};

document.addEventListener("keydown", event => {
    keys[event.key] = true;
});

document.addEventListener("keyup", event => {
    keys[event.key] = false;
});

Puis dans update() :

function update(dt) {
    if (keys["ArrowRight"]) {
        player.x += player.speed * dt;
    }
    if (keys["ArrowLeft"]) {
        player.x -= player.speed * dt;
    }
    if (keys["ArrowUp"]) {
        player.y -= player.speed * dt;
    }
    if (keys["ArrowDown"]) {
        player.y += player.speed * dt;
    }
}

8. Interaction avec la souris

La position de la souris peut être récupérée relativement au Canvas. 

canvas.addEventListener("mousemove", event => {
    const rect = canvas.getBoundingClientRect();

    const mouseX = event.clientX - rect.left;
    const mouseY = event.clientY - rect.top;

    console.log(mouseX, mouseY);
});

Cette technique permet de créer :

  • des boutons graphiques ;
  • des jeux ;
  • des applications de dessin ;
  • des interfaces interactives.
Attention :

getBoundingClientRect() est indispensable si le Canvas est redimensionné ou décalé par CSS. Sans cela, les coordonnées souris ne correspondent pas aux coordonnées Canvas.
